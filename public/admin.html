New Post Generator

Since your site is 100% free and static, use this tool to generate the code for your new posts.

How to use:

  1. Fill out the form below.
  2. Click "Generate JSON Code".
  3. Copy the code and paste it into `public/data/posts.json`.
  4. Push your code to GitHub to publish.

Tip: Place your images in `public/assets/` and use `assets/filename.jpg`.

Use <p>, <h3>, <b>, <ul> tags.
